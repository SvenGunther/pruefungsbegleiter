# Prüfungsbegleiter

Werkzeug für Prüfungsvorsitzende zur Beobachtung und Bewertung von Lehrproben, praktischen und mündlichen Staatsprüfungen im Thüringer Vorbereitungsdienst – auf Grundlage der standardisierten Leistungsbilder.

## Veröffentlichen mit GitHub Pages

1. Auf github.com anmelden und ein neues Repository anlegen (z. B. `pruefungsbegleiter`).
2. „uploading an existing file“ wählen und `index.html`, `.nojekyll` und `README.md` hochladen, dann „Commit changes“.
3. Unter **Settings → Pages** bei „Source“ *Deploy from a branch* wählen, Branch `main`, Ordner `/ (root)`, speichern.
4. Nach ein bis zwei Minuten ist die Seite erreichbar unter `https://<benutzername>.github.io/pruefungsbegleiter/`.

## Datenschutz

- Alle Eingaben (Beobachtungen, Noten, eigene Dokumente) werden **nur im Browser des jeweiligen Geräts** gespeichert (localStorage). Nichts wird an GitHub oder einen Server übertragen.
- Die Seite selbst ist öffentlich abrufbar, sie enthält aber keine personenbezogenen Daten.
- Regelmäßig über *Wissensbasis → Alles exportieren* sichern; auf einem anderen Gerät über *Importieren* einlesen.
- Personenbezogene Beobachtungen nach Abschluss des Verfahrens im *Archiv* löschen.

## Ergänzen

Neue Dokumente, Fragen, Theorien und Indikatoren lassen sich direkt in der Seite unter *Wissensbasis* hinzufügen. PDFs werden im Browser gelesen. Die Funktionen „Mit Claude ausformulieren“ und „Auswerten“ stehen nur in der Claude-Version der Seite zur Verfügung.
